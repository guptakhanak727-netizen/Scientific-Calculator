# Scientific Calculator

A web-based **Scientific Calculator** built using HTML, CSS, and Python. This application combines a clean, responsive front-end interface with a powerful Python back-end to handle complex mathematical operations.

## 🚀 Features

* **Basic Operations:** Addition, subtraction, multiplication, and division.
* **Scientific Functions:** Trigonometry (sin, cos, tan), logarithms (log, ln), exponents, and square roots.
* **Advanced Math:** Factorials, percentages, and pi (π) constants.
* **Responsive Design:** Smooth, modern UI that works flawlessly on desktop, tablet, and mobile screens.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3
* **Backend:** Python 3.x (with Flask)

## 📦 Installation & Setup

Follow these steps to run the project locally on your machine.

### Prerequisites
Make sure you have Python installed. You can download it from [python.org](https://python.org).

### Steps

1. **Clone the Repository**
   ```bash
   git clone https://github.com
   cd scientific-calculator
   ```

2. **Set Up a Virtual Environment (Optional but Recommended)**
   ```bash
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate
   ```

3. **Install Dependencies**
   ```bash
   pip install flask
   ```

4. **Run the Application**
   ```bash
   python app.py
   ```

5. **Access the App**
   Open your web browser and navigate to `http://127.0.0`.
